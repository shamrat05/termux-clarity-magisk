# Termux Clarity v1.0.4

Adds the Warm Graphite palette:

- Deep warm-charcoal background instead of cool slate.
- Soft ivory foreground instead of cool white.
- Muted red, green, amber, blue, violet, and teal accents with clear contrast.
- Keeps the installed Droid Sans Mono font and existing Termux key layout.

The palette was applied to the live Termux config and installed Magisk module. Run `termux-reload-settings` to reload colors in the active Termux app; opening a new session also applies them.
